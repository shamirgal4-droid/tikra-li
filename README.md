# תקריא לי 📷🔊

אפליקציה שמקריאה דפים: מצלמים דף מהמורה, והאפליקציה מקריאה אותו בעברית או באנגלית.

- **חינם לגמרי.** אין הרשמה, אין פרסומות ואין שרת בתשלום.
- **פרטיות:** התמונות והטקסט לא יוצאים מהמכשיר. גם זיהוי הטקסט וגם ההקראה רצים בתוך הטלפון.
- **עובד בכל מכשיר:** אנדרואיד, אייפון, טאבלט ומחשב. אפשר להוסיף אותה למסך הבית כמו אפליקציה רגילה.
- **עובד בלי אינטרנט** אחרי השימוש הראשון.

## מה אפשר לעשות בה

- צילום דף או בחירה של כמה תמונות מהגלריה. הדפים נקראים לפי הסדר.
- **מהירות ההקראה:** כפתורי 🐢 ו-🐇, מחוון, ו-5 מהירויות מוכנות (×0.5 עד ×2). כשמשנים מהירות באמצע, ההקראה ממשיכה מאותה מילה במהירות החדשה.
- הדגשה של המשפט ושל המילה שמוקראים, והגלילה עוקבת אחרי ההקראה.
- לחיצה על מילה מתחילה להקריא ממנה. יש גם כפתורים למשפט הקודם, למשפט הבא ולהקראה חוזרת של המשפט.
- תיקון ידני של הטקסט אם הזיהוי טעה.
- הגדלה והקטנה של הטקסט ובחירת קול.
- עברית ואנגלית יחד: כל משפט מוקרא בקול של השפה שלו.

## מגבלות שחשוב להכיר

- **טקסט מודפס בלבד.** כתב יד לא מזוהה.
- **ניקוד:** טקסט מנוקד מזוהה פחות טוב מטקסט בלי ניקוד.
- **איכות הצילום קובעת:** כדאי לצלם ישר מלמעלה, באור טוב ובלי צל.
- **הקול הוא הקול של המכשיר.** אם אין קול עברי, יש בהגדרות ⚙️ הוראות להתקנה בחינם.

## איך מפיצים לתלמידים

1. שולחים לתלמידים את הקישור לאתר.
2. בטלפון פותחים את הקישור:
   - **אנדרואיד (כרום):** תפריט ⋮ ← "הוספה למסך הבית".
   - **אייפון (ספארי):** כפתור השיתוף ← "הוספה למסך הבית".

## פרטים טכניים

- אתר סטטי בלבד: HTML, CSS ו-JavaScript, בלי שלב build.
- זיהוי טקסט: [Tesseract.js](https://github.com/naptha/tesseract.js) (רישיון Apache-2.0), עם מודלי `heb` ו-`eng` מסוג `best_int`. כל הקבצים נמצאים בתיקייה `vendor/`, כך שאין תלות בשרתים חיצוניים.
- לפני הזיהוי התמונה עוברת עיבוד מקדים: יישור תאורה כדי לבטל צל, ומתיחת ניגודיות.
- הקראה: Web Speech API (`speechSynthesis`).
- אחסון: GitHub Pages, עם workflow שנמצא ב-`.github/workflows/pages.yml`.
